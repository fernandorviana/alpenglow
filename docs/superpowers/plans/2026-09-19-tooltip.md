# Tooltip — implementation plan

> **For agentic workers:** executed inline in the session that wrote the spec (superpowers:executing-plans). Short on purpose, like `2026-09-18-tabs.md`: the spec carries the decisions and numbers, this carries the order.

**Goal:** `Tooltip` in the package — the drawn overlay card and a compact size, opened by hover and keyboard focus — with its contrast cases and the `/tooltip` docs page.

**Architecture:** One client component wrapping its trigger in an inline-flex `span` that owns the anchor name and the listeners; a `popover="manual"` panel placed by CSS anchor positioning. Open state lives in the platform (`showPopover`/`hidePopover`), timers in refs; no React state.

**Tech Stack:** React 19, TypeScript, CSS Modules, Vitest 5 + jsdom + Testing Library with fake timers, `src/test/popover.ts`, axe through `src/test/axe.ts`.

**Spec:** `docs/superpowers/specs/2026-09-19-tooltip-design.md`.

## Global Constraints

- **Do not commit**; stage by path when asked.
- No colour literals; motion tokens only; `box-sizing` declared; every `var(--ap-…)` real; `'use client'`; the Compiler lint (no synchronous `setState` in an effect).
- The edge is `border/subtle`, never `border/default` (Fernando, 2026-09-19); a test holds it.
- Compound selectors only — a variant or size class on the element it styles (the Tabs lesson).
- The Figma key stays out of the repository. `npm run check` and `npm run build:docs` before reporting.
