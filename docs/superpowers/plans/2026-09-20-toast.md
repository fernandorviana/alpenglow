# Toast — implementation plan

> **For agentic workers:** executed inline in the session that wrote the spec (superpowers:executing-plans). Short on purpose, like `2026-09-19-tooltip.md`: the spec carries the decisions and numbers, this carries the order.

**Goal:** `toast()` and `Toaster` in the package — a simple toast on the inverse surface, floating in a corner — with its contrast cases and the `/toast` docs page.

**Architecture:** A module store (`store.ts`: list, listeners, `toast`, `dismiss`, `subscribe`, `snapshot`) with no React in it, read by one client component through `useSyncExternalStore`. `Toaster` is an always-mounted named region, a `popover="manual"` shown while it has toasts. Clocks live in the Toaster, one per visible toast, held while the region is hovered, focused or the document hidden.

**Tech Stack:** React 19, TypeScript, CSS Modules, Vitest 5 + jsdom + Testing Library with fake timers, `src/test/popover.ts`, axe through `src/test/axe.ts`.

**Spec:** `docs/superpowers/specs/2026-09-20-toast-design.md`.

## Global Constraints

- **Do not commit**; stage by path when asked.
- No colour literals; motion tokens only; `box-sizing` declared; every `var(--ap-…)` real; `'use client'`; the Compiler lint (no synchronous `setState` in an effect, no component reassigning a module variable).
- The surface is `surface/inverse`; the ring is `currentColor`, never `border/focus`; no tone colour. Tests hold the first two.
- Compound selectors only.
- The Figma key stays out of the repository. `npm run check` and `npm run build:docs` before reporting.
