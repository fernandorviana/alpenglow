# Alert — implementation plan

> **For agentic workers:** executed inline in the session that wrote the spec (superpowers:executing-plans). Short on purpose: the spec carries the decisions and numbers, this carries the order.

**Goal:** `Alert` in the package — the drawn `Notification status`, with soft edges and an outline action — with four border tokens, its contrast cases and the `/alert` docs page.

**Architecture:** One presentational component, no state; the caller owns whether it shows. The status vectors move out of the Toaster into `statusGlyphs.tsx`, shared by both.

**Tech Stack:** React 19, TypeScript, CSS Modules, Vitest 5 + jsdom + Testing Library, axe through `src/test/axe.ts`.

**Spec:** `docs/superpowers/specs/2026-09-20-alert-design.md`.

## Global Constraints

- **Do not commit**; stage by path when asked.
- No colour literals; motion tokens only; `box-sizing` declared; every `var(--ap-…)` real; compound selectors only.
- Tokens are edited in `theme.ts` and regenerated with `npm run build:css`; `src/styles/*.css` is never edited by hand.
- The Figma key stays out of the repository. `npm run check` and `npm run build:docs` before reporting.
